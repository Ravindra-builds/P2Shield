Member 2 · Tech lead1:30 – 3:00 · about 210 words
Slide 3 · Technical approach · 90 seconds
DOMove your hand left to right along the architecture diagram as you talk.

Thank you. Here is the full flow, from left to right.

You type in any chat box: ChatGPT, Claude, Gemini, or any other site. Our shield sits on top of it, inside a closed Shadow DOM, so the website cannot read what we find.

The core engine is pure TypeScript and runs on the device. Three detectors work together. Rule detectors use real checksums: Luhn for cards, Verhoeff for Aadhaar, mod-97 for IBAN, so a random 12-digit number is not flagged as Aadhaar. The field detector reads structure, like JSON, .env files, headers and tables. Heuristics catch names, medical terms and amounts. If the laptop supports it, Chrome’s built-in Gemini Nano adds context, also on the device.

Then the resolver merges overlaps, the policy engine picks an action for each data type, we score the risk before and after, and the sanitizer writes the safe text back into the box, with Undo.

DOPoint to the Privacy Actions panel.

There are six actions: mask, tokenize, redact, generalize, remove secret, and keep. For example, age 27 becomes “20 to 30”. Passwords and keys are always removed, in every profile.

One rule we never break: the AI model only labels. Our policy makes every decision.

Q&A: likely questions

The listed member answers in under 30 seconds; others add one line only if needed. If you don’t know, say so honestly: “That isn’t in the prototype yet. Here’s how we would do it…”. Never claim a feature we don’t have.

QuestionShort answerWho
How is this different from existing DLP tools or ChatGPT Enterprise?They block AI or send prompts through a cloud proxy (one more server holding your data), and need IT setup. ChatGPT Enterprise protects only one product. P2Shield works on any chat site, even personal accounts, fully offline, and rewrites instead of blocking, so people keep working.M1
What if it misses something?It reduces exposure; it isn’t a 100% guarantee. Rules catch formats and field names, Smart mode adds context, and the user sees every finding in Details. Known weak spots: numbers written as words and unusual names.M2
Won’t it flag normal text by mistake?Checksums (Luhn, Verhoeff, mod-97) and field-name context keep false alarms low. A test set of normal prompts (code, SQL, essays, logs) must come out unchanged. Any item can be unticked.M2
Does the AI still answer well with placeholders?Yes. Tokens stay consistent ([PERSON_1] is always the same person), generalizing keeps meaning (age range, state), and facts the task needs, such as a diagnosis, are kept.M1
Can the website still read what I type?Honestly, a site’s own scripts can see its text box while you type. P2Shield protects what gets sent, and our findings sit in a closed Shadow DOM. For very sensitive text, use the Playground and paste only the safe version.M2
Do you store any data?No text and no values. The audit log keeps only time, site, counts and risk (last 200 entries, clearable). The token map lives in memory only.M4
What about prompt injection?We don’t detect injections, but we remove the values an injection would try to steal. The AI model gets the text as fenced data and can never mark a secret as “needed”.M2
What hardware does Smart mode need?Chrome’s built-in Gemini Nano: desktop Chrome, about 22 GB free disk, a GPU with more than 4 GB VRAM or 16 GB RAM. It’s optional; without it, Basic mode protects instantly.M2
Which browsers? Mobile? Desktop apps?Chromium browsers: Chrome, Edge, Brave. Smart mode is Chrome only. Desktop apps and mobile are on the roadmap (an organisation gateway).M3
How does a company enforce it?IT pushes the policy through Chrome managed storage: profile, lock, disabled sites. It’s implemented, but we haven’t tested it on a real company rollout yet.M4
How will you make money?Free for individuals; per-seat plan for organisations (central policy, audit log, support). No servers, so running costs stay very low.M4
Is it built for India?Yes: Aadhaar with the Verhoeff check, PAN, GSTIN, IFSC, UPI, Indian phone numbers, and amounts rounded in lakh. Hindi support is next.M1
Can it put the real names back in the AI’s answer?Not yet; it’s first on our roadmap. The token map stays on the device, so we can swap [PERSON_1] back on the user’s screen only.M3
Large documents? PDFs or images?Text up to 400,000 characters; 20,000 characters take under 8 ms. PDF, DOCX and OCR for images are on the roadmap.M3

Before you go on stage

The day before

  • In the project folder: npm install, then npm run build.
  • Chrome → chrome://extensions → Developer mode → Load unpacked → choose the dist folder. Pin the P2Shield icon.
  • Full rehearsal 2–3 times with a timer. Write the real names into this script.
  • Record a 2-minute backup video of the demo on the same laptop.
  • Export the deck as PDF too, in case PowerPoint fails.

30 minutes before

  • Start the demo page: npm run demo (leave that terminal open).
  • Tab 1: http://localhost:4173/. Tab 2: P2Shield settings, Privacy policy = Personal. Tab 3 (optional): chatgpt.com, logged in.
  • Browser zoom 125–150% so judges can read. Close all other tabs.
  • Turn on Focus Assist / Do Not Disturb. Laptop charged, HDMI adapter ready.
  • Test Alt+Shift+S once (chrome://extensions/shortcuts).
  • Slideshow open on slide 1. Practise one Alt+Tab both ways.
After every rehearsal, set Privacy policy back to Personal. Demo step 4 switches it to Healthcare, and the step 1 numbers only match with Personal.
